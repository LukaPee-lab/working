# AI resources

This directory contains reusable, company-neutral AI workflow resources.

## Available packages

- [`portable-workflows`](portable-workflows/README.md): five Codex skills for evidence-backed handoffs, improvement tracking, interactive checklists, privacy-aware context transfer, and asset-based UI composition.

The repository-level marketplace manifest is stored at `.agents/plugins/marketplace.json` so Codex can discover the package when this repository is added as a marketplace source.
